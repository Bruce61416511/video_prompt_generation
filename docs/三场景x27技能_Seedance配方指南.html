〇、先理清数字

上游 awesome-seedance 共 27 个场景模板（docs/templates/en/ 全量目录；其中 13 篇被打包成 agents/skills/ 技能，14 篇只有文档），另有 2 个非场景工具（production-workflow 生产流程、prompt-library 模板总索引）。找模板优先翻 27 篇全量目录，只看技能包目录会漏 14 个。

一、心法：27 个不是 27 个平等选项

它们分两种角色：

23 个主角 决定片型 —— 一条提示词只选 1 个当骨架。

4 个底座 技术件 —— 被主角借用，按需叠 1~3 个。

用不好的最大原因是混骨架：把两个主角的结构各抄一半，模型两头不讨好。正确姿势永远是「1 主角 + N 底座」。

三、4 个底座的挂法

底座何时挂关键动作
timeline-shot-script
官方原话：全语料最承重的结构		几乎必挂逐秒切连续时间段（不留断档）；每拍一个景别 + 一个主动作 + 一条声音
character-reference-lock画面里有必须保持同一的人/产品/角色逐条写继承什么 + 单独逐条写不继承什么——inherit-nothing-else 条款是区分好锁和坏锁的分水岭
dialogue-performance-beats有台词 / 有对话声明语言 → 标记说话人 → 反应写因果链（不是表情清单）→ 每拍以明确终态闭合
storyboard-grid-to-video多镜头顺序要求严格 / 图解感两段式：先用图像模型出单页编号分镜格，再把格图喂给视频模型连接

四、组合规则

1. 一条提示词 = 1 个主角 + 1~3 个底座，最多再叠 1 个质感件（如 handheld-ugc-vlog 给带货做旧）。
2. 底座永不单独出片，主角永不互相混合。
3. 骨架可迁移（官方认证的复用姿势）：time-freeze-rewind 的案例里，同一位作者用不同物理材料复用同一套五拍骨架——语料直接引用它证明骨架可迁移。即：保留主角的时间轴骨架，只替换主体和物理材质，是这套库最高的复用方式。

六、公共铁律（27 个技能的共同签名）

1. 双锁分离：人和产品 / 角色和场景各锁各的，且必须写"不继承什么"。
2. timeline 承重：任何配方最终落在逐秒时间轴上；时间段连续不重叠、不留断档。
3. 对白焊动作：台词写在它被说出的那一拍里；反应写因果链。
4. 字全部后期：模型渲 logo / slogan / 包装文字必崩，留干净尾帧，文字进剪映贴。
5. 单拍单事件：一拍只堆一种物理效果；单镜≥1秒；写"过程变化"不写"静态状态"。

七、通用生产五步法

  1. 路由 —— 从 27 篇模板目录按意图 match 模板 useWhen。判断不准就先问清（"产品视频"可能是广告轨道也可能是 UGC 测评）。产出：一个技能名。
  2. 锚定 —— 打开该技能 references/cases.md，选 1 条离需求最近的案例对标（品类近、时长近、质感近）。铁律：只选 1 条，绝不取平均。产出：锚定案例链接。
  3. 填空 —— 按技能 Workflow 的结构块逐块填，每块必须有内容（空块就是提示词变虚的地方）。产出：完整草稿提示词。
  4. 自查 —— 对照该技能 Guidance + Pitfalls 逐条过：微距指名拍什么、一拍一种物理效果、单镜≥1秒、别渲字、质感二选一、参考图定终帧就直说。产出：修订后提示词。
  5. 验收 —— 拿 production-workflow 的 qa-rubric 逐帧看成片；失败按固定格式记录：镜头/时间点 + 观察 + 窄修复（只修坏镜头，不重写整条；对比同模型同设置）。产出：QA 记录。

八、学习路径（别 27 个平均用力）

第一步：吃透 4 个底座（timeline / reference-lock / dialogue-beats / storyboard-grid）——它们出现在几乎所有配方里，投入产出比最高。

第二步：精通业务相关的 3 个主角——带货 ugc-creator-review；品牌 product-commercial-shotlist + cinematic-narrative-short；科普 process-transformation-montage。

第三步：其余 20 个当字典——接到什么拍什么，翻到对应技能照结构块填空，不用背。

九、一句话选型

带货 = ugc-creator-review + 双锁 + 钩子拍。

品牌 = 按调性挑主角 + timeline 与 reference-lock 双底座。

科普 = ugc-creator-review（讲师）+ process-transformation-montage（过程）+ dialogue-performance-beats（问答）。
