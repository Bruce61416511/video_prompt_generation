# 带货视频 8 种形式 · 输入模板清单

> 用法：先选形式 → 照该形式的模板逐行填【】→ 粘进 http://127.0.0.1:8099
> 平台硬限：单段 ≤30 秒，超了拆段逐段生成再剪辑拼接。

---

## 〇、先分清 8 种形式属于哪一类

真正决定骨架的只有一个变量：**人和产品的关系**。

| 大类 | 形式 | 人的角色 | 钩子逻辑 |
|---|---|---|---|
| **A 对镜头讲** | ① 站桩口播测评<br>② 开箱测评<br>⑦ 对比测评 | 讲解者，看镜头 | 动作 + 声音 |
| **B 在故事里** | ③ 剧情小剧场<br>④ 场景 Vlog 植入<br>⑧ 反差钩子短片 | 角色，不看镜头 | 有悬念的情境 |
| **C 没有人** | ⑤ 纯产品质感片<br>⑥ 吃播 / 使用 ASMR | 无（或只有手） | 产品一个强烈动态 |

---

## 一、5 行「公用不变式」（8 种形式都要，内容基本不用改）

```
产品：【产品名】
产品拆件：【袋身材质颜色／盖子结构／内容物颜色与质地】
核心卖点（只选1个）：【…】
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不说治疗/改善/增强免疫力/通便/降三高；画面不渲字，价格卖点字卡后期贴
```

补充两条通用铁律（填的时候守住）：
- 产品印字只说「袋面有印刷」，**绝不指定文字内容**（AI 渲中文必崩，字后期贴）；
- 一拍只堆一种物理效果（液体、烟雾、粉末别混在同一个镜头）。

# A 类 · 对镜头讲

## ① 站桩口播测评（营养师/博主对镜头）

```
带货口播【15-30】秒【9:16·生成时选竖屏】：真人测评【产品名】
产品拆件：【袋身材质颜色（含"偏紫罗兰，never纯蓝"这类锚）／盖子结构／内容物颜色质地】
出镜人设：【性别＋年龄段＋身份＋穿搭一句话，如：28岁女营养师，燕麦针织+亚麻围裙】
核心卖点（只选1个）：【如：整果打浆+益生菌发酵，花青素更好吸收】
前3秒钩子＝【一个变化动作＋一个声音，如：拧盖"啵"一声，紫红液体涌出袋口特写】
中段演示：【动作链，如：倒半杯对光看挂壁→喝一口回味→指袋身讲卖点】
收尾：产品独占画面一拍→人拿产品看镜头＋【一句引导语】
她说话像聊天分享、不像广告，例句：“【一句体感描述，如：喝完嘴里不齁，像蓝莓果泥很清爽】”
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不说治疗/改善/增强免疫力/通便；画面不渲字，价格卖点字卡后期贴
```
**特有必填**：出镜人设、中段动作链、引导语。
**禁忌**：台词写成广告腔slogan（要第一人称感受句）；产品印字指定具体文字。

## ② 开箱测评（手部为主，脸可只露半张）

```
带货开箱【20-30】秒【9:16·生成时选竖屏】：手部特写开箱【产品名】
产品拆件：【包装外的快递箱/礼盒 + 袋身材质颜色／盖子／内容物】
出镜方式：只露手与半身，不露全脸；【手部特征：指甲干净、无夸张饰品】
前3秒钩子＝【包裹被划开的"嗤啦"声 + 箱盖翻开、第一件产品露出一角】
开箱序列：划开封条→取出【几袋】→撕开单袋外膜→拿出产品→正反面各转一次给镜头
中段演示：【逐个展示：袋身/盖子/倒出液体】，并说【一句体感台词】
收尾：【几袋产品在桌面排成一排的全景】→ 手拿起一袋转向镜头＋【一句引导语】
她/他说话像聊天分享、不像广告，例句：“【体感描述】”
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不说治疗/改善/增强免疫力/通便；袋面只说"有印刷"不指定文字；画面不渲字
```
**特有必填**：开箱序列（顺序不能乱）、手部特征。
**禁忌**：让模型渲包装上的具体文字；开箱动作写得太密（每秒一个动作会糊）。

## ⑦ 对比测评（自己 vs 自己 / 泛化品类对比）

```
带货对比【20-30】秒【9:16·生成时选竖屏】：真人对镜头做对比测评【产品名】
产品拆件：【本方产品外观】；对比物：【泛化描述，如"市面常见果汁饮料一杯"，不点名任何品牌】
出镜人设：【性别＋年龄段＋身份＋穿搭一句话】
前3秒钩子＝【两杯并置，一杯浑浊一杯清透，手指依次点过去 + 一声轻敲玻璃】
对比维度（3 个以内）：【颜色／挂壁质地／配料表（字后期贴）／喝后口腔感受】
中段演示：左右手各拿一杯→同时倒出→并置对比→喝本方产品→【反应动作】
收尾：只举起本方产品看镜头＋【一句不贬低对手的结论，如"我更愿意选发酵的"】
她说话像聊天分享、不像广告，例句：“【体感描述】”
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不点名、不贬低任何竞品；不做功效对比；画面不渲字，配料表字卡后期贴
```
**特有必填**：对比物（必须泛化）、对比维度（≤3 个）。
**禁忌**：点名竞品、暗示竞品有害（广告法高风险）；用"更好/最好"这类绝对化用语。

# B 类 · 在故事里

## ③ 剧情小剧场（产品自然出现）

```
带货剧情【25-30】秒单条【9:16·生成时选竖屏】
产品：【产品名】
产品拆件：【袋身材质颜色／盖子／内容物】
场景设定：【时间＋地点＋人物＋正在发生的小事，如：周三早晨7点半，厨房，女儿上学前手忙脚乱】
角色：【1-2 人外观：年龄、发型、服装；同一角色全片不换装】
前3秒钩子＝【一个有悬念的情境，不是产品特写，如：妈妈一手拎书包一手翻冰箱，什么都没找到】
产品怎么自然出现：【如：她拉开冰箱最下层顺手拿到→单手拧盖→仰头喝一口→长舒一口气】
卖点怎么带出来：【台词顺口一句，或镜头推近袋身（字后期贴），不打断剧情】
收尾：回到产品＋【一句点题的话，如"忙的时候，至少这口是对的"】
台词像日常对话、不像广告，例句：“【一句生活化台词】”
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不说治疗/改善/增强免疫力/通便；画面不渲字，价格卖点字卡后期贴
```
**特有必填**：场景设定、角色外观、产品出现动作、点题话。
**禁忌**：人物停下来对着镜头讲卖点（会瞬间破戏）；一条 30 秒片里塞 2 个以上剧情转折。

## ④ 场景 Vlog 植入（跟拍一天）

```
带货Vlog【25-30】秒单条【9:16·生成时选竖屏】
产品：【产品名】
产品拆件：【袋身材质颜色／盖子／内容物】
主角人设：【年龄＋职业感＋穿搭，如：30岁新媒体运营，灰卫衣+棒球帽】
拍摄风格：手持跟拍、自然光、轻微晃动与对焦漂移（手机实拍感，不要电影感）
时间线（3 个片段，每段 8 秒左右）：【07:20 出门前 → 12:40 工位下午 → 18:30 回家路上】
产品出现位置：中段自然入镜，方式：【从包里掏出/桌上早已放着一袋】
台词方式：前半段旁白式自言自语（“今天又是三场会”），产品出现时转成【对口播一句】
收尾：【回到桌面，产品在旁边，镜头缓缓停下】＋【一句轻收尾】
说人话、别广告腔，例句：“【一句日常感叹】”
质感：手机实拍测评感（固定，不选广告感）
合规红线：不说治疗/改善/增强免疫力/通便；画面不渲字
```
**特有必填**：主角人设、3 个时间点、产品出现的段位与方式。
**禁忌**：Vlog 里塞完整产品讲解（Vlog 的卖点是"生活里有它"，不是"介绍它"）；画面过于精致（失去真实感）。

## ⑧ 反差钩子短片（meme 式）

```
带货反差总长【15-30】秒【9:16·生成时选竖屏】：一个包袱的短视频，产品是包袱落点
产品：【产品名】
产品拆件：【袋身材质颜色／盖子／内容物】
角色：【1 人外观，表演一本正经、不夸张扮丑】
前3秒钩子＝【强反差动作，如：她把一袋深紫色饮品倒进高脚杯，表情像在喝红酒】
铺垫：【预期建立，如：同事以为她在喝什么高级货，凑过来问】
包袱（第【8-12】秒）＝【预期反转，如：她淡淡说"蓝莓后生元，公司冰箱拿的"】
产品露出方式：包袱落点处产品必须在画面里【举起来/放桌面正中】
收尾：【产品特写一拍 + 一句反转台词】
表演纪律：镜头稳、光正常、动作克制（荒诞感来自设定，不来自浮夸表演）
说人话、别广告腔，例句：“【一句反差台词】”
质感二选一：【手机实拍测评感／投放级广告感】
合规红线：不拿身体状况/疾病开玩笑；不说治疗/改善类词；画面不渲字
```
**特有必填**：反差设定（预期 vs 现实 各一句）、包袱落点时间。
**禁忌**：一个 30 秒里塞两个包袱（模型拍不出节奏）；夸张表演+花哨运镜（廉价感）。

# C 类 · 没有人

## ⑤ 纯产品质感片（无人物）

```
带货产品片【15-30】秒【9:16·生成时选竖屏】：无人物出镜
产品：【产品名】
产品拆件：【袋身材质（哑光/亮面）、袋身颜色（含 never 纯蓝 这类锚）、盖子结构与颜色、内容物颜色与质地】
环境与布景：【如：深灰石材台面 + 一束侧逆光；或纯色背景 + 水花】
美学词（开头定调）：【premium beauty-commercial aesthetics／clean minimal／暗调高级感 三选一】
前3秒钩子＝【一个强烈产品动态，如：袋身从画面上方落下、稳稳立住，袋内液体晃出漩涡】
中段质感镜头（3-4 个，一拍一种物理效果）：【光扫过哑光袋身／紫红液体冲入玻璃杯／杯壁冷凝水珠滑落】
收尾：【产品定格英雄帧，留干净空白区给后期字卡】——画面不渲任何文字
质感：投放级广告感（固定）
合规红线：不说任何功效词；画面不渲字，价格卖点字卡后期贴
```
**特有必填**：环境布景、美学词、3-4 个质感镜头（一拍一种效果）。
**禁忌**：同一镜里混多种物理效果；镜头低于 1 秒（切太碎模型解析不出）；让画面出现文字。

## ⑥ 吃播 / 使用 ASMR

```
带货ASMR【15-30】秒【9:16·生成时选竖屏】：只出手部与近景，不露全脸
产品：【产品名】
产品拆件：【袋身材质颜色／盖子／内容物颜色质地（挂壁、果肉感）】
镜头：微距/探针镜头感，浅景深，声音优先
画面-声音配对（铁律：一拍一个可见变化 + 一个配套声音）：
  ① 手指扣住螺旋盖 → 拧开"啵"的一声
  ② 液体倒进玻璃杯 → 连续的"咕咚"流淌声
  ③ 端起杯对光轻转 → 液体挂壁的细微黏稠声
  ④ 喝一口 → 吞咽声 + 轻轻呼气
  ⑤ 杯壁冷凝水珠滑落 → 极轻的水滴声
卖点带出：【台词一句体感描述，或最后字卡（后期）】
收尾：【空杯/空袋 + 桌上一滴水痕，静一秒】
台词像聊天、不像广告，例句：“【口感体感，如：不齁，咽下去有回甘】”
质感：手机实拍测评感（固定，别写广告感，会失去 ASMR 的亲密感）
合规红线：不说治疗/改善/增强免疫力/通便；不出现夸张功效反应（如捂肚子）；画面不渲字
```
**特有必填**：画面-声音配对清单（5 拍）、卖点出口。
**禁忌**：只写画面不写声音（ASMR 的一半是声音）；一个镜头里做两件事。

## 附：填完自查 5 条（8 种形式通用）

1. **钩子是不是"过程"**？写"产品摆在桌上"=状态，不合格；要"正在发生的事"。
2. **卖点是不是只有 1 个**？两个以上必然互相稀释。
3. **有没有让它渲字**？出现"Text／slogan／具体文字"字样就删掉，改"留干净尾帧"。
4. **时间填了没有、超 30 秒拆段没有**？断档和塞爆都源于此。
5. **合规红线还在不在**？治疗/改善/增强免疫力/通便/降三高 → 一律删。
